## وضع الـDEMO الحالي

`docker compose up -d` من جذر المستودع يرفع: عقدة EVM محلية (31337) + نشر العقود تلقائياً + PostgreSQL مهاجَرة ومزروعة بمؤسسة `INST-CENTRAL-DEMO` + المحرك على :8005 + الواجهة على :3005 (تمرر /api داخلياً).
الدليل الكامل: [demo-readiness.md](demo-readiness.md). الواجهة تحمل شعار DEMO مربوطاً بوضع التشغيل الحي (app_mode) — يختفي تلقائياً في الوضع المؤسسي.

## التحويل من demo إلى institutional

البنية جاهزة — التحويل = تشغيل بيئة staging بدل الديمو:
`docker compose -f infra/staging/docker-compose.staging.yml -f infra/staging/docker-compose.kms.yml -f ops/monitoring/docker-compose.monitoring.yml up -d`
هذه تشغل: PostgreSQL 16 بدور تطبيق محدود + Keycloak حقيقي (دخول PKCE) + Vault KMS (مفاتيح بلا ملفات) + العاملين + المراقبة. الفروقات: هوية موثقة إلزامية، مفاتيح KMS، عزل RLS مفروض — لا هوية تجريبية ولا اختصارات.

## ما يفصلنا عن "منصة حقيقية" — بالترتيب

### 1. قرار المستخدم: مدقق العقود الخارجي (H02) — الحاجز الأمني الأكبر
اختيار مدقق مستقل وسمعة، حزمة الفحص جاهزة (R01–R04 + خارطة الثوابت). زمنه 2–4 أسابيع خارجية. **لا نشر حقيقي قبل إغلاقه.** الجزء الآلي الموازي: بوابة فحص التبعيات جاهزة (H03-SCA مدمجة)، واختبار الاختراق الخارجي يبقى قرار شراء.

### 2. قرار المستخدم: بيانات حقيقية للبحث (H09→H10)
اتفاقية تصدير CSV مُجهل الهوية من جهة → نفس الفصل الزمني الصارم → قرار ML بالبوابة (تفعيل أو نتيجة سلبية صادقة). الأنابيب كلها جاهزة ومثبتة على بيانات تجريبية.

### 3. قرار المستخدم: جهة تجريبية موقعة (H11→H12)
Runbook التهيئة (H11) + تجربة 30 يوماً بمعايير خروج قابلة للقياس + توقيع بشري حقيقي (accepted_by/pilot_owner). تقويمي ولا يُضغط.

### 4. مهام ميكانيكية جارية/متبقية (تُتم آلياً)
- H08 تدريب استعادة مُقاس (بعد H07) — RPO≤15د/RTO≤120د تُقاس.
- H11 حزمة تهيئة التجربة.
- H14 المتبقي: تنظيف 2 أيقونة lucide، بوابة تغطية اختبارات، اختبار انحدار لرفض توكن KMS الخاطئ 403.

### 5. بعد التجربة (DG5)
خطة 22 أكتوبر: الفوترة والاشتراكات، لوحة المنظّم (دور REGULATOR جاهز في العقود)، تقارير الامتثال CBI/FATF، onboarding متعدد المؤسسات.

## قواعد ثابتة

- institutional لا يعرف الهوية التجريبية ولا RPC بديلاً ولا hashes مختلقة —demo يعرفها بوضوح وشعار.
- كل إغلاق finding يتطلب دليل بناء فعلي — لا علامات بلا اختبار.
- البيانات الحقيقية لا تُرفع لأي مكان عام؛ اتفاقياتها موقعة.

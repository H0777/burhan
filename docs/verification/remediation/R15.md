## 1. What was fixed (F11 Closure)

1. **Empirical Dependency Probes (No Mock Successes):**
   - `check_db_connectivity`: Executes an active `SELECT 1` query via SQLAlchemy engine. Fails closed upon connection error or timeout.
   - `check_migration_status`: Checks alembic head revision on PostgreSQL via `verify_schema_revision`, or verifies tables on SQLite.
   - `check_kms_vault_readiness`: Verifies evidence vault writeability and KMS/KeyProvider access using an isolated probe file (`.health_probe_tmp`).
   - `check_evm_rpc_responsiveness`: Calls `blockchain_listener.get_node_health()` to inspect actual JSON-RPC reachability, block height, and node status.

2. **Graceful Degradation Without Cascading Crashes:**
   - When external dependencies (e.g., EVM RPC node offline) or core components fail:
     - Status code: Explicit HTTP `503 Service Unavailable`.
     - Response status: `"degraded"` (or `"starting"` for startup probe).
     - Health flags: `live=True` (process remains responsive), `ready=False`.
     - Diagnostic reasons: Details contain explicit error messages in `details["reasons"]` without leaking credentials, SQL DSNs, or auth tokens.

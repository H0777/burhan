## 6. بنود أخرى

- **الجلسة والتخزين**: حالة OIDC في sessionStorage (WebStorageStateStore)، ربط المحفظة العابر في الذاكرة فقط، يُمسح عند logout؛ لا localStorage لأي حالة جلسة، ولا طباعة tokens في السجلات.
- **410**: يظهر كـ`ApiError.legacyGone` مع مؤشر V3 من المتن، ولافتة UI صريحة «legacy results NOT auto-accepted» (CaseWorkspace)؛ لا قبول تلقائي لنتائج قديمة.
- **رفع HTTP فقط**: شارة anchor تُظهر pending/submitted مع نص «not blockchain-anchored»؛ عبارة النجاح على السلسلة تظهر فقط لـANCHORED.
- **ملفات خارجة عن قائمة المهمة عُدّلت**: `frontend/src/utils/aiClient.test.js` فقط (كان متتبعاً وتعطّل بسبب تغيير aiClient المقصود — أُضيف mock لgetRuntimeConfig). لا شيء غيره.
- **غير مُختبر (خارج نطاق R13)**: اختبار البناء المقدَّم عبر nginx وsame-origin الفعلي → R20؛ تشغيل OIDC ضد issuer حقيقي (Keycloak) → بيئة الاختبار المؤسسي (R14/R20)؛ واجهة V3 حية → بعد هبوط R07.

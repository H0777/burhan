## 3. Database Indexing & Query-Plan Optimization

To guarantee sub-10ms query execution as dataset size scales past $10^5$ records, targeted compound indexes were established in `ai-engine/app/db/models.py`:

1. **`ix_tx_inst_sender_occurred`:** Compound index on `(institution_id, sender_ref, occurred_at)`. Reduces 24-hour rolling velocity lookups in `FeatureService.calculate_features()` from an $O(N)$ full table scan to an $O(\log N)$ b-tree range lookup.
2. **`ix_cases_inst_status_created`:** Compound index on `(institution_id, status, created_at)`. Optimizes paginated case list views and prevents sort spill.
